# Client_Query_Management_System
This project will help to get queries from user and manage the queries by support team.


In this project we first import pandas for read csv file,sqlalchemy for manage database for read and write data from sql,streamlit for web page, and hashlib used for encode the password. Then read csv file by pandas and connected database connection as variable name engine after that create table for sql query and executed python sql connection. First we set session state login page for get user name and password by user.Session state nothing but whenever we click button and redirect some page. In login page user will give username,password and role.If user press login button then it will check all the details given or not in login page. If in role client_page selected it will redirect to client page in that page user will give email,mobile no, heading and description for query. And submit the queries so this datas will append on the csv file. If in role support_page selected it will redirect to support page in that page will manage support team.This team will see all queries or closed queries or open queries by using filter option. By filter option will show that data depend on filter option.This data will retrieve from sql database. Finally, the team will close the query and that closed time automatically set when team close the query. After that team will logout by press logout button and will redirect to login page.
